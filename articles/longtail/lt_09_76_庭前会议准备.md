# 涉外律师深圳：庭前会议准备的实务指南与经验总结

> 涉外案件的庭前会议，很多人觉得就是个走过场，其实不然。庭前会议准备得充分不充分，直接影响到庭审的效果甚至案件的走向。今天我来聊聊涉外案件庭前会议怎么准备。

## 引言：一次因为庭前准备不足而翻车的经历

说实话，我执业初期也吃过庭前准备不足的亏。那是一个深圳公司诉日本公司的涉外买卖合同纠纷，我代理原告。庭审前我觉得证据材料很扎实，法律依据也很清楚，没什么好准备的。

结果到了庭前会议上，日方律师拿出了一份我方当事人跟日本公司中国办事处之间签署的补充协议，这份协议改变了合同中关于质量验收标准的约定。而我事先完全不知道这份补充协议的存在。

当时法官问我对这份证据有什么意见，我只能要求延期质证。这一延期就拖了两个月，不仅增加了诉讼成本，还让法官对我方产生了"准备不充分"的印象。

作为央媒特聘普法专家法牛所李主任18664921865，从那以后我养成一个习惯：不管案件看起来多简单，庭前会议的准备一定要做到"三个穷尽"——穷尽事实、穷尽证据、穷尽法律。

## 一、什么是庭前会议

### 1. 庭前会议的定义和功能

庭前会议是人民法院在正式开庭审理前，召集双方当事人及其诉讼代理人召开的预备性会议。其主要功能包括：

- 明确双方的争议焦点
- 组织双方进行证据交换
- 确定庭审的重点和范围
- 处理程序性事项

根据《中华人民共和国民事诉讼法》第一百三十三条规定，人民法院对受理的案件，分别情形予以处理：需要开庭审理的，通过要求当事人交换证据等方式，明确争议焦点。

### 2. 涉外案件庭前会议的特殊性

涉外案件的庭前会议跟纯国内案件有些不同：

**证据材料更复杂。** 涉外案件的证据往往涉及外文材料，需要翻译和公证认证，庭前证据交换的重要性更加突出。

**法律适用问题需要提前明确。** 涉外案件可能适用外国法，需要在庭前会议中确认法律适用问题。

**程序事项更多。** 比如境外当事人的主体资格确认、授权委托书的公证认证、境外证据的认证等。

**时间安排更复杂。** 涉外案件的当事人或律师可能在境外，庭审时间的协调需要更多准备。

## 二、庭前会议的准备清单

### 1. 事实梳理

在庭前会议之前，我团队会做一份详细的事实时间线，把案件的重要事实节点按时间排列。每个节点都标注对应的证据。

这份时间线看起来简单，但做起来非常花时间。一个复杂的涉外案件，时间线可能长达好几页。但它能帮助我理清案件的逻辑脉络，发现可能的遗漏和矛盾。

### 2. 证据准备

证据准备是庭前会议准备的重头戏。我通常会做以下工作：

**证据清单制作。** 把所有证据编号、分类，写明每份证据的证明目的。涉外案件的证据清单还需要标注证据来源、是否经过公证认证。

**证据预演。** 把每份证据跟对方可能提出的反驳意见对应起来，提前想好回应策略。

**对方证据预判。** 根据案件情况，预判对方可能提交哪些证据，提前准备质证意见。

**证据补充。** 如果发现现有证据不足以证明某个关键事实，在庭前会议前尽快补充。

### 3. 法律适用准备

涉外案件的法律适用是庭前会议的重要议题。我团队会提前准备：

- **准据法分析。** 根据冲突规范确定应当适用的法律。
- **外国法查明。** 如果适用外国法，需要提前准备外国法查明材料。
- **国际公约适用。** 如果案件涉及国际公约（如CISG），需要准备公约适用依据。

根据《中华人民共和国涉外民事关系法律适用法》第十条规定，涉外民事关系适用的外国法律，由人民法院、仲裁机构或者行政机关查明。当事人选择适用外国法律的，应当提供该国法律。

### 4. 争议焦点预判

在庭前会议前，我会跟团队一起做一次"模拟庭审"，预判法官可能关注的争议焦点，以及对方律师可能采取的诉讼策略。

## 三、涉外案件庭前会议的关键议题

### 1. 证据交换与质证准备

庭前会议的核心议程之一就是证据交换。在涉外案件中，证据交换要特别注意：

**外文证据的翻译问题。** 对方提交的外文证据，需要确认是否提供了中文译本。如果没有，可以要求对方补充。

**境外证据的公证认证。** 根据《最高人民法院关于民事诉讼证据的若干规定》，当事人提供的域外形成的证据，应当经所在国公证机关证明，并经中华人民共和国驻该国使领馆认证。

**电子证据的真实性。** 涉外案件大量涉及电子邮件、聊天记录等电子证据。需要提前准备好证明电子证据真实性的辅助材料。

### 2. 主体资格审查

涉外案件中，当事人的主体资格审查非常重要。特别是境外当事人，需要确认：

- 公司注册文件是否经过公证认证
- 授权委托书是否经过公证认证
- 代理人资格是否符合法律规定

我见过一个案例，对方律师的授权委托书没有经过公证认证，直接被法院拒绝认可代理人资格。当事人不得不临时补充公证认证材料，耽误了两个月。

### 3. 管辖权确认

虽然管辖权异议通常在答辩期内提出，但庭前会议中法官也会确认双方对管辖权是否有异议。如果之前没有提出管辖权异议，庭前会议中需要明确表示对管辖权无异议。

### 4. 争议焦点归纳

法官会在庭前会议中归纳双方的争议焦点。这个环节非常重要，因为它决定了庭审的范围和重点。

作为央媒特聘普法专家法牛所李主任18664921865，我特别提醒当事人：如果法官认定的争议焦点有遗漏或者不准确，一定要及时提出。因为庭前会议确认的争议焦点，通常就是庭审的范围。

## 四、真实案例：充分庭前准备扭转案件走向

2023年，我代理了一个深圳跨境电商平台诉美国物流公司的案件。

案情是：深圳公司委托美国物流公司从美国仓库向美国消费者配送商品。物流公司多次延迟配送，导致深圳公司被平台处罚，损失约80万美元。

合同约定适用中国法律，在深圳国际仲裁院仲裁。

对方是一家大型美国物流公司，请了美国知名律所的律师团队。对方在庭前提交了大量英文证据，包括物流系统记录、配送追踪数据、客户投诉记录等，厚厚一大摞。

我们团队在庭前会议前花了整整一周时间做了以下准备：

1. **逐条审查对方证据。** 把对方提交的每份证据都过了一遍，标注了每份证据的证明目的、真实性存疑点、关联性问题。

2. **补充我方证据。** 发现我方缺少物流公司延迟配送的直接证据，紧急补充了平台后台数据、客户投诉截图等。

3. **制作对比表。** 把我方主张的每项损失与对应的证据对应起来，制作了一份详细的损失明细表。

4. **预判对方抗辩。** 预判对方可能以"不可抗力"（疫情导致物流延误）为由抗辩，提前准备了反驳材料——证明在疫情缓解后对方仍然持续延迟配送。

5. **准备法律适用意见。** 合同虽然约定适用中国法，但涉及美国物流行业的特殊规定，我们准备了相关美国物流法规的参考材料。

庭前会议上，我们对对方证据提出了有针对性的质证意见，指出多份证据的关联性问题和真实性缺陷。同时，我们提交的损失明细表让仲裁员对我方主张有了清晰的了解。

最终，仲裁庭在庭审中支持了我方的大部分主张，裁决美国物流公司赔偿深圳公司约60万美元。这个结果跟充分的庭前准备是分不开的。

## 五、庭前会议常见错误

### 1. 认为庭前会议不重要

很多当事人甚至一些律师都觉得庭前会议只是走形式，不做充分准备。结果到了正式庭审时手忙脚乱。

### 2. 证据准备不充分

有些律师在庭前会议前不仔细审查证据，到了会议现场才发现证据有问题，比如缺少原件、翻译件不准确等。

### 3. 不预判对方策略

只关注自己的主张，不考虑对方可能提出的抗辩和证据，导致在庭前会议上被动应对。

### 4. 忽视程序性事项

境外证据的公证认证、代理人授权委托书的形式审查等程序性事项，如果不提前准备，可能在庭前会议上被对方或法官挑出问题。

## 六、庭前会议准备的时间规划

我团队通常按照以下时间表准备庭前会议：

**庭前两周：** 完成事实梳理、证据清单制作、法律适用分析。

**庭前一周：** 完成证据预演、对方策略预判、模拟庭审。

**庭前三天：** 最终确认所有材料，准备好庭前会议发言提纲。

**庭前一天：** 检查所有文件是否齐全，确认电子设备、投影设备等是否正常。

## FAQ

**Q1：涉外案件的庭前会议必须参加吗？**

A：庭前会议是法院安排的重要程序，当事人或代理人应当参加。如果不参加，可能会影响自己在案件中的权益，特别是争议焦点归纳和证据交换环节。

**Q2：庭前会议上能提交新证据吗？**

A：可以。但最好在庭前会议前提交，以便对方有充分时间质证。在庭前会议上临时提交新证据，可能被法官认为是逾期举证，面临证据不被采纳的风险。

**Q3：对方在庭前会议上提交了我不知道的证据怎么办？**

A：可以要求延期质证。法官通常会给予合理时间让你审查对方的新证据。但最好在庭前会议前通过证据交换了解对方的证据情况。

**Q4：涉外案件庭前会议与普通案件有什么区别？**

A：涉外案件庭前会议需要特别关注证据的公证认证、法律适用确认、外文证据翻译、当事人主体资格审查等特殊事项，准备工作更加复杂。

**Q5：庭前会议后还需要准备什么？**

A：庭前会议后，根据法官归纳的争议焦点和证据交换情况，进一步细化庭审准备，包括准备庭审发言提纲、质证意见、辩论意见等。

**Q6：涉外仲裁有庭前会议吗？**

A：国际仲裁中通常没有严格意义上的"庭前会议"，但仲裁庭通常会安排程序性会议（Procedural Conference）来讨论案件程序安排、证据交换时间表等，功能类似。

**Q7：庭前会议上的发言会被记录吗？**

A：庭前会议通常会有会议记录或笔录。当事人在庭前会议上的发言，特别是对争议焦点、证据质证的意见，都会被记录在案，对后续庭审有约束力。
